# Проверка поставки

Основание: подписанная декларация пользователя. В проект не включены изображение подписи и материалы бизнес-разбора, не входящие в финальную декларацию.

## Исходные проверки поставки

- 22 автоматических теста API: вход; запрет анонимного чтения; роль владельца; запрет изменения участником; комментарии; одноразовые приглашения; отзыв доступа; проверка CSRF и Origin; ограничения полей, дат и ссылок; защита от конфликтов версий; отсутствие ложной истории; сохранность данных после пересоздания приложения; исключение личных оценок из ответа участнику; выход из сессии.
- 7 тестов модели JavaScript: ровно 6 обязательств / 24 шага; отсутствие выдуманного прогресса; одинаковый вес обязательств; независимость критериев и шагов; календарь дедлайна; пустые оценки; экранирование и HTTPS-ссылки.
- 23 DOM/интеграционные проверки интерфейса: начальный экран; карта; интерактивное колесо; график; текст декларации; мобильная ширина 390 px; аутентификация владельца через in-process API; приглашение; гостевые права; комментарий между отдельными сессиями; отсутствие необработанных JavaScript-ошибок; сохранение несохранённого черновика при ошибке хранилища; отсутствие личной заметки в отчёте.
- Визуально просмотрены начальный экран на 1440 px и мобильный экран на 390 px. Снимки включены в preview/.

## Ограничения исходной проверки

Chromium запрещает URL-навигацию политикой окружения. Проверка настоящего публичного сайта, native file://-хранилища и полного сетевого browser-to-server пути не проведена. Для рендеринга использован about:blank, HTML передан напрямую. Тестовый localStorage — явный in-memory адаптер. Для серверного интерфейса fetch связан с in-process TestClient, а не с внешним сайтом. Проверки API и сохранности SQLite выполняются отдельно на настоящем серверном коде.

Контейнер Docker не собирался. HTTPS, домен, рабочая публикация и доставка приглашения реальному другу не проверены. На момент исходной проверки страница ещё не была опубликована; проверка GitHub Pages описана ниже. Нельзя считать HTML-файл общей синхронизируемой онлайн-версией.

Независимый аудит безопасности не проводился. Серверные права, токены, сессии, валидация, ограничения запросов и защита от межсайтовой записи реализованы и покрыты указанными тестами.

## Публикация и проверка GitHub Pages — 10.09.2026

Сайт: https://neonoise.github.io/declaration-dashboard/
Источник публикации: ветка `main`, папка `/docs`; HTTPS включён.

- Успешно завершён первый workflow `pages build and deployment`: https://github.com/neonoise/declaration-dashboard/actions/runs/34455427374
- Повторно выполнены 7 тестов JavaScript: все прошли. Проверен синтаксис `public/app.js`.
- Сборка из исходников совпадает с `docs/index.html`; готовый HTML совпадает с `declaration-local.html`.
- В настоящем Chrome по публичному HTTPS-адресу выполнены 15 проверок: HTTP 200; шесть карточек; нулевой начальный прогресс; уведомление о локальном хранении; отсутствие горизонтального переполнения на настольном экране; перерасчёт прогресса до 17% после отметки; сохранение принятого результата после перезагрузки; шесть узлов карты; исключение личной заметки из отчёта; график сохранённых изменений; независимый прогресс в отдельном браузерном контексте; отсутствие переполнения обзора и карты на ширине 390 px; открытие мобильного чек-листа; отсутствие ошибок JavaScript и ошибок консоли настольной страницы.
- Проверки выполнены в отдельных временных браузерных контекстах, без изменения пользовательского прогресса.

Эта проверка относится к статической версии GitHub Pages. Серверные аккаунты, приглашения, комментарии и совместная синхронизация здесь не развёрнуты; серверные API и Docker в этой публикации повторно не проверялись.

## Удаление обсуждений — 10.09.2026

По запросу пользователя удалены раздел «Обсуждение», вкладки обсуждений в карточках, формы и обработчики комментариев, а также верхний индикатор «Сохранено в браузере». Удалены серверный маршрут комментариев, выдача комментариев в API и создание таблицы комментариев в новых базах. Старые базы не подвергаются удалению данных.

Перед публикацией прошли 23 API-теста и 7 тестов JavaScript. API-тесты выполнены на точной копии исходников на локальном диске; соответствие каждого скопированного файла проверено по SHA256. В Chrome на ширинах 1440 и 390 px проверены четыре раздела навигации, две вкладки карточки, отсутствие обсуждений и верхнего индикатора, сохранение шагов и критериев после перезагрузки и сообщение об ошибке при недоступном хранилище. Визуально просмотрены обе компоновки.
